# Almacenamiento de la aplicación

El código usa Supabase cuando el proyecto actual tiene configuradas sus variables de almacenamiento y autenticación. `esquema.sql` conserva la referencia incluida en el ZIP; no se ha comprobado ni modificado la base desplegada.

Antes de publicar, revisar la configuración del proyecto real de Vercel y conservar sus accesos y datos. No ejecutar el esquema ni crear otra base sobre la existente sin comprobar su estado. No guardar credenciales en GitHub ni copiar variables de la demo al servicio real.

Esta preparación se verificó con pruebas locales y datos ficticios. No se hicieron conexiones ni cambios a una base de reportantes real.
